# meta-learning-analogy-SLM

Code and datasets used for the project: **"Inducing Structural Mapping: A Few-Shot Meta-Learning Approach to Analogical Reasoning in Small Language Models"**

## Overview
Language models often encode the relation linking a source pair but fail to transfer it to a target pair, defaulting to surface similarity. Following the diagnostic work of Lee et al. (2026), which localises this bottleneck at the mapping stage rather than at relation extraction, we apply a few-shot meta-learning framework to analogical reasoning. Across episodes, the model must infer the common relation from a small study set and apply it to complete an analogy. We evaluate three Qwen2.5 models (1.5B, 3B and 7B) trained on items from [AnalogyKB](https://github.com/siyuyuan/analogykb) and [BATS](https://vecto.space/projects/BATS/) against a baseline fine-tuned without a study set. Meta-trained models improve significantly over the baseline, even on relations unseen during training.

## Data
The dataset was constructed by selecting items from AnalogyKB and BATS across fifteen analogical relations. Items were initially analyzed employing the `evaluate_knowledge.py` script from [Lee et al. (2026)](https://github.com/dmis-lab/analogical-reasoning/tree/main). The results were then used to construct both training and testing episodes.

### Generating the Episode Datasets
1. Run `evaluate_knowledge.py` (Lee et al., 2026) on your chosen model, using `data/evaluate_knowledge_input.jsonl` as the input relation items;
2. Run `src/episode_builder.py` on the output generated by `evaluate_knowledge.py`.
The output generated consists of the files `train_episodes_(model_size).jsonl` and `test_episodes_(model_size).jsonl`.

### Episode Example
```
{
  "relation": "capital",
  "study_set": [["India", "New Delhi"], ["Japan", "Tokyo"], ["Finland", "Helsinki"]],
  "query": "France",
  "target": "Paris"
}
```

**Note:** because `episode_builder.py` filters out shortcuts from the training datasets and removes items unknown to the model from the testing datasets, the constructed episodes are strictly specific to the chosen model and size.

## Running Experiments
To run the training and testing pipelines, execute the bash script `experiments/train_test.sh`. Model selection and other parameters can be customized within the script.

To analyze the results run `src/process_results.py`.

_**Note:** the code was adapted from [Bertolazzi et al. (2026)](https://github.com/leobertolazzi/meta-learning-logic).
GitHub Copilot was used during development._
