# meta-learning-analogy-SLM

Code and datasets used for the project: **"Inducing Structural Mapping: A Few-Shot Meta-Learning Approach to Analogical Reasoning in Small Language Models"**

## Data
The dataset was constructed by selecting items from [AnalogyKB Wikidata](https://github.com/siyuyuan/analogykb) and [BATs](https://vecto.space/projects/BATS/). Items were initially analyzed employing the `evaluate_knowledge.py` script from [Lee et al. (2026)](https://github.com/dmis-lab/analogical-reasoning/tree/main). The results were then used to construct both training and testing episodes.

### Directory Content
* `evaluate_knowledge_input.jsonl`: selected relations from AnalogyKB and BATs, serving as the input for `evaluate_knowledge.py`;
* `train_episodes_(model_size).jsonl`: input data for both meta-training and baseline fine-tuning (model-specific);
* `test_episodes_(model_size).jsonl`: input data for evaluation and testing (model-specific).

### Generating the Episode Datasets
1. Run `evaluate_knowledge.py` (Lee et al., 2026) on your chosen model, using `evaluate_knowledge_input.jsonl` as the input relation items;
2. Run `episode_builder.py` (located in the `src/` folder) on the output generated by `evaluate_knowledge.py`.

**Note:** because `episode_builder.py` filters out shortcuts from the training datasets and removes items unknown to the model from the testing datasets, the constructed episodes are strictly specific to the chosen model and size.


## Source Code

### Directory Content
* `test.py`
* `train.py`
* `utils.py`

* `process_results.py`

### Running Experiments
To run the training and testing pipelines, execute the bash script `train_test.sh` located in the `experiment` folder. Model selection and other parameters can be customized within the script.
To analyze the results run `process_results.py`.
